# WasteWise — Waste Segregation System (20% Demo)

> **College project demo — Stages 1–3 of the pipeline only.**
> Classifies waste images into **Biodegradable · Recyclable · Non-Recyclable · Hazardous**
> using MobileNetV2 transfer learning.

---

## Project Structure

```
waste-segregation/
├── backend/
│   ├── preprocess.py        # Stage 1+2: Image intake & preprocessing
│   ├── train_model.py       # Stage 3: Fine-tune MobileNetV2 + save model
│   ├── app.py               # Flask REST API  (/classify endpoint)
│   └── model/               # Created by train_model.py
│       └── waste_classifier.h5
├── data/
│   ├── raw/                 # Original dataset (gitignored)
│   │   ├── Biodegradable/Organic/{coffee_tea_bags,egg_shells,…}
│   │   ├── Recyclable/Recyclable/{cans_all_type,glass_containers,…}
│   │   ├── Hazardous/Hazardous/{batteries,e-waste,paints,pesticides}
│   │   └── Non-Recyclable/Non-Recyclable/{ceramic_product,diapers,…}
│   └── processed/           # Generated by preprocess.py (gitignored)
│       ├── train/{Biodegradable,Recyclable,Non-Recyclable,Hazardous}/
│       └── val/{Biodegradable,Recyclable,Non-Recyclable,Hazardous}/
├── frontend/
│   ├── index.html           # Single-page upload + classify UI
│   └── bins_hero.jpg        # Hero image
└── venv/                    # Python virtual environment
```

## Prerequisites

- Python 3.11+
- Virtual environment already created at `venv/`
- Required packages already installed: `tensorflow`, `flask`, `pillow`, `numpy`

Activate the venv before every step:

## Step 1 — Preprocess the Dataset

**What it does:** Walks `data/raw/`, collects up to 250 images per category,
resizes each to 224×224, normalises pixel values, and writes PNG files into
`data/processed/train/` and `data/processed/val/` (80/20 split).

```bash
python backend/preprocess.py
```

Expected output:
```
[Biodegradable]  total=250  train=200  val=50
[Hazardous]      total=250  train=200  val=50
[Non-Recyclable] total=250  train=200  val=50
[Recyclable]     total=250  train=200  val=50
══════════════════════════════════════════
Preprocessing complete!
```

> **Tip:** Adjust `MAX_PER_CLASS` in `preprocess.py` to trade off between
> speed and model accuracy. 250/class gives ≈ 5–8 min training on CPU.

---

## Step 2 — Train the Model

**What it does:** Fine-tunes MobileNetV2 (ImageNet weights) on the 4 waste
categories using two phases:
- **Phase 1** (5 epochs): trains only the new classification head (base frozen)
- **Phase 2** (10 epochs): unfreezes the top 30 MobileNetV2 layers for fine-tuning

Saves `backend/model/waste_classifier.h5` when done.

```bash
python backend/train_model.py
```

Expected total time:
- **CPU only:** ~8–15 minutes
- **Apple Silicon (Metal GPU):** ~3–6 minutes

Watch for final validation accuracy in the last line of output.

> **Note:** `tensorflow-metal` is already installed, so Apple Silicon GPU
> acceleration is active automatically.

## Step 3 — Run the Flask API

```bash
python backend/app.py
```

The server starts on **http://localhost:5050**

Endpoints:
| Method | URL | Description |
|--------|-----|-------------|
| `GET`  | `/health` | Check if model is loaded |
| `POST` | `/classify` | Classify an uploaded image |

### Test the API with curl

```bash
curl -X POST http://localhost:5050/classify \
     -F "image=@/path/to/your/image.jpg"
```

Example response:
```json
{
  "category": "Recyclable",
  "confidence": 0.8741,
  "bin_colour": "Blue",
  "bin_label": "Recycling Bin",
  "tip": "Recyclable — rinse and place in the blue recycling bin.",
  "all_scores": {
    "Biodegradable": 0.0412,
    "Hazardous": 0.0211,
    "Non-Recyclable": 0.0636,
    "Recyclable": 0.8741
  }
}
```

```
        │
        ▼

        ▼

        │

        │
        ▼
  UI Result Card (colour-coded bin, confidence bar, all-class scores)
```

## Troubleshooting

| Problem | Fix |
|---------|-----|
| `Model not found` error in Flask | Run `train_model.py` first |
| `Cannot reach the server` in browser | Start `app.py` on port 5050 |
| Training very slow | Lower `MAX_PER_CLASS` in `preprocess.py` to 100 |
| Low accuracy (<60%) | Increase `MAX_PER_CLASS` to 400+ and re-run both scripts |
| Port 5050 already in use | Change `port=5050` in `app.py` and `API_URL` in `index.html` |
